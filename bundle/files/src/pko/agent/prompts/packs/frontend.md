## Пак: пользовательский интерфейс

В репозитории найден код интерфейса. Точка входа здесь — действие пользователя,
а не HTTP-маршрут.

Где искать: `onClick=`, `onSubmit=`, `addEventListener(`, `v-on:`, `@click`,
`st.button(`, `st.form_submit_button(`, обработчики роутера
(`useNavigate`, `<Route`), изменения состояния (`useState`, `dispatch(`,
`store.commit(`).

Как размечать:

- обработчик события — `ENTRYPOINT` / `serve` / `ui_event`;
- переход экрана или изменение состояния — `STATE` / `transition`;
- запрос к бэкенду (`fetch`, `axios`) — `EFFECT` / `call` / `http_client`;
- компонент экрана — `COMPONENT`.

Осторожно: статический разбор PKO не читает JS/TS — по этим файлам ты
единственный источник. Тем важнее ссылка на строку: непроверяемое утверждение
будет отброшено.
