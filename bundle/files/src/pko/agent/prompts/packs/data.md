## Пак: работа с данными

В репозитории найден доступ к данным. Различай чтение и изменение: от этого
зависит проверка допуска «только чтение».

Где искать: строки SQL (`SELECT … FROM`, `INSERT INTO`, `UPDATE … SET`,
`DELETE FROM`), вызовы ORM (`session.add`, `session.commit`, `.query(`,
`.objects.filter(`), файловые операции (`open(..., 'w')`, `write_text`),
объектные хранилища (`put_object`, `download_file`).

Как размечать:

- `SELECT` — `EFFECT` / `read` / `sql`; `INSERT`/`UPDATE`/`DELETE` — `EFFECT` /
  `write` / `sql`;
- то же через ORM — механизм `orm`;
- файл — `fs`, S3 и аналоги — `object_storage`, документная база — `nosql`.

Осторожно: запрос, собранный конкатенацией в рантайме, статически не виден.
Если изменение данных возможно, но в коде не доказано, скажи об этом словами в
`guardrail_invariants`, а не выдавай предположение за факт.
