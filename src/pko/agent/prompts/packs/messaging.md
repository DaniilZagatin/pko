## Пак: очереди и обмен сообщениями

В репозитории найден обмен сообщениями через брокер или очередь задач.

Где искать: `KafkaProducer`, `producer.send(`, `basic_publish(`,
`.apply_async(`, `.delay(`, `@task`, `KafkaConsumer`, `.consume(`,
`receive_message(`, объявления топиков и exchange.

Как размечать:

- отправка сообщения — `EFFECT` / `emit` / `queue`;
- обработчик входящего сообщения — `ENTRYPOINT` / `serve` / `queue`;
- чтение из очереди — `EFFECT` / `read` / `queue`;
- входящий вызов извне — `ENTRYPOINT` / `serve` / `webhook`;
- размер батча, таймаут ожидания, число повторов — `CONTROL` / `limit`.

Осторожно: имя топика из переменной окружения — не доказательство маршрута
сообщения. Указывай строку объявления, а не место использования.
